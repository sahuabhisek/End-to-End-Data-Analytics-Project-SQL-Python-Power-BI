# Customer Shopping Behavior Analysis
## End-to-End Data Analytics Project | SQL + Python + Power BI

## Project Overview

The Customer Shopping Behavior Analysis project focuses on analyzing customer purchasing patterns, shopping preferences, product performance, and customer segmentation.

This project combines SQL, Python, and Power BI to transform customer shopping data into meaningful business insights.

## Project Objectives

- Analyze customer purchasing behavior.
- Understand revenue contribution by gender.
- Identify top-rated and frequently purchased products.
- Compare shipping methods and purchasing patterns.
- Analyze subscription and repeat customer behavior.
- Segment customers based on previous purchases.
- Build an interactive Power BI dashboard.

## SQL Analysis

The project includes the following business queries:

1. Revenue Analysis by Gender.
2. Discount and Spending Analysis.
3. Top 5 Products by Average Rating.
4. Shipping Analysis.
5. Subscription Analysis.
6. Customer Segmentation using CASE WHEN.
7. Top 3 Products in Each Category using DENSE_RANK().
8. Repeat Buyer and Subscription Analysis.
9. Age Group Revenue Analysis.
